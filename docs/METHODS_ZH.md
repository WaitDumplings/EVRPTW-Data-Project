# 已审核的方法、依据与边界

目标是构造一个有来源支持、可复现的“城市路网及潜在配送地点”模型。源记录、模型推理、
准入假设与实际观测分别记录。全国使用同一套来源组合和规则，不按城市增加地方parcel数据。

## 城市、边界与路网

11城使用Census Vintage 2025人口背景和冻结的TIGER/Line 2025行政/陆地区域；行政区是
benchmark地理域，不宣称等于真实公司的服务区域。OSM固定为2026-10-25T21:21:21Z的7个区域PBF。
道路保留实际有向连接和城外上下文，不合成跨组件边。0/1/2/5/10/20km节点范围全部检查后，
选取能覆盖最大可恢复城市公共节点的最小范围；不能用全城百分比提前停止。

公共路网与terminal接入分开。private、destination/customers和service道路不参与公共穿行。
普通private道路和private gate按本次配送获得邀请/授权建模，保留
`delivery_authorization_assumed=true`和`owner_permission_observed=false`。
这与[OSM private标签](https://wiki.openstreetmap.org/wiki/Tag:access%3Dprivate)的个别许可语义相容，
不等于逐地点查到业主同意。[destination](https://wiki.openstreetmap.org/wiki/Tag:access%3Ddestination)
也不允许一般穿行；把service作为terminal是本模型的统一保守约束。

明确禁行、配送禁行、locked、不支持的物理障碍以及已识别军事、情报、执法、监狱、核设施等
敏感场地继续排除。普通民用机场货运区、港口和商业private地点不因类别整体排除。
不确定接入应标待核，不能为方便舍弃而改称敏感单位。

## Customer location

来源为Microsoft Global 2026-08-13主轮廓、冻结legacy补缺、NSI与OSM。Microsoft的release年份
不是逐栋影像年份；NSI于2026-10-26获取，属性源年份混合，不是2026逐房普查。
NSI原始occupancy编码提供住宅类型证据，户数单独保留。

Microsoft补缺先保留有效新版轮廓、剔除精确规范化几何重复，并用无效新版轮廓的包络作为
保守禁补区域。旧版候选必须与新版/保护几何严格相距10m以上；旧版重复和正面积重叠冲突
保留在审核表中。2/5/10/20m为同一全国敏感性对照，10m是工程保护间隔，不是已验证的位置误差界。
NSI随后按唯一几何包含匹配；加入旧版不能破坏已有新版唯一匹配。原始NSI户数上下界只作
来源证据，不能据此替代最终nullable户数或重新分类户型。旧的按户数判断house/apt函数没有带入。

一个独立house或一个有来源支持的apartment小区算一个潜在配送地点。小区允许多栋楼。
尚未识别为小区的地点保留provisional范围，不能主张所有真实小区已完全归并。
`residential_units`是nullable辅助估计：有可靠site总数只记一次；仅对有证据的非重叠楼栋
组成求和；范围或重叠无法确认则保留未知。一个NSI记录只有一个site owner能阻止处理重复，
但不证明真实住户完全不重叠。楼栋数量、面积和NSI来源行数不代替户数。

## Depot location

OSM提供仓库、承运、物流办公等候选证据。同一物理地点允许多个公司合并；按唯一
`facility_group_id`计数，不按公司或来源成员采样。普通office=logistics保留B类；
泛工业和无支持的零售/非地面办公点不能因此升级。面积为属性/敏感性标记，不是硬门槛。
地址100m、支持园区1000m、重叠比例80%和坐标1m为固定归并假设，不称真实企业组织边界。

## 投影与真实接入

Customer保留完整轮廓/已识别小区范围，使用源几何到道路的最近几何对；不以house中心替代。
Depot从原内部代表点投影，原生OSM范围仅用于确定局部候选搜索尺度。
Motorway/trunk及其link等不能承载地点投影，但允许合规道路用于穿行。

最近物理道路先接受许可、方向、敏感区、水体、不可承载道路交叉及customer邻楼障碍检查。
建筑障碍或有向断连这两类软失败可查最多8条不同严格许可OSM way；范围为原gap加2倍
源范围bbox对角线，无范围的点为2倍原gap。硬失败不通过另找道路绕过。
没有合格候选则保留源地点及户数，默认池标待核。

每个terminal分别保存通往公共参考SCC的真实有向入/出OSM链、网关、长度和源边身份。
几何connector和真实道路长度分开。只在OD对中物化源出路与目的地入路，避免公共穿行捷径。
1km只作QA，不能自动删除源house。LA指定house继续待核。入口未实测、未建模的turn restrictions、
conditional access及未标注障碍仍是限制；固定网关不保证所有入口下的OD最优，也不假定矩阵对称或满足三角不等式。

## Charging与速度

AFDC GPS/Point独立准入，地址作辅助验证，不能只凭OSM同地址覆盖原生坐标。
同址合并但保留设备、接口和访问条件；先找兼容设备配置，再处理缺失功率，不合并设备功率或端口数。
参考车为原生J1772 AC11kW和CCS1 DC100kW上限。功率来源/年份/缺失状态单独记录；
0.90降额为透明benchmark工程假设，不是由能量效率证明的通用平均充电功率。

法定速度优先OSM方向maxspeed、通用maxspeed、方向核实的HPMS 2018证据，再分层插补。
运行速度使用7州COMM-MD/sourceType32先验：2023 NEI速度分布、统一StreetLight小时/日权重，
2023月VMT折算。速度观测为2022-01至2023-05，商业小时/日权重有效期为2022-11至2023-05。
`rho = VMT/VHT有效速度 / 周末低流Q85`，道路参考速度为法定速度乘rho。
这是州级商用车情景，不是每城、每条边或EDV实测速率。规范SQL输入可独立复算7州系数。

充电地点/参数和速度的规则代码已整理，但在新路网上的统一重绑定仍待完成。完整CLE结构、
组装与instance activation不属于本版本；逐地点住宅户数也没有在这里被转成实际日订单需求。

## 本轮生产证据

上游11城得到4,214,699个可用customer、7,555个可用depot组；源安全地点仍保留42,638个
customer和232个depot组待核。1,742,450条terminal路径通过核验，所有可用几何connector的
>1km数量为0。源身份、几何、NSI所有权和户数不变。详见evidence中的数量、原因、模型来源表。
这些是上游完整生产结果；新项目的移植测试、打包测试和可选真实图回放另行记录。
